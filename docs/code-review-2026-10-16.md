## 검증 범위

- 변경 전 전체 `npm test`와 `npm run build` 통과.
- 변경 후 Node 22에서 전체 테스트와 타입 검사·프로덕션 빌드 실행.
- 실제 테마 편집 JSX의 입력 핸들러 → 저장 페이로드 → ThemeManager 효과 실행 검증.
- 일반 이름/낮·밤 이름 혼합 목록, 과거 태그의 요청 사본 정리, 전역 선호, 고정 모드 보존 검증.
- PGlite에서 새 SQL 실행 후 기존 색상·체크값 보존, 기본값, 오래된 분기 상태 정리, RLS, 다크 선호 가드 검증.
- 실제 검색 페이지 핸들러의 순서가 뒤집힌 요청·빈 검색·실패, 하트의 null 조인·삭제 실패·성공, 작품 복제 페이로드 회귀 검증.
- main.tsx와 sw.ts에서 정적 import와 동적 import를 따라간 결과 미참조 소스 모듈은 발견하지 못함. 이것이 모든 함수의 도달 가능성을 증명하는 것은 아님.

운영 환경 변수와 로그인 세션을 사용하지 않았다. 운영 DB 적용, 실제 계정으로 전체 화면 순회, 유료 LLM 호출, 실기기 브라우저 UI 검증은 미실행이다. 기존 테스트의 mock 및 PGlite 검증을 운영 서비스의 종단 간 검증으로 간주하지 않는다.

## 의존성 점검

현재 lockfile 기준 `npm audit --json` 결과: **18개 취약 의존성 항목(높음 12, 보통 6, 치명적 0)**. 동일 원인에 따른 전이 의존성과 상위 패키지 집계가 포함되어 있어 독립적인 공격 경로 18개를 뜻하지 않는다.

Vite, Tailwind, PWA 플러그인에는 major 업그레이드가 제시되며, React Router, PostCSS 및 여러 전이 의존성에도 경고가 있다. 이 앱은 정적 프런트엔드이므로 개발 서버·빌드 도구·SSR 관련 경고를 곧바로 운영 데이터 침해로 해석해서는 안 된다. 다만 브라우저 런타임에 들어가는 라우터와 개발/빌드 경고를 분리해 후속 업데이트가 필요하다. 강제 자동 수정은 하지 않았다.
