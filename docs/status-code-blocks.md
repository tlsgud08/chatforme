# 상태창 유형

선택 순서는 **기본, 레거시, 네온 단말, 기업 기밀, 한지 기록, 와시 두루마리, 판타지 서책, 필름 느와르, 파스텔 노트**입니다.

- 기본은 최종 시안에서 레거시라고 표시했던 형태이며 현재 테마 팔레트를 따릅니다.
- 레거시는 기존 `MarkdownCodeBlock`을 그대로 렌더링합니다. 고정 색상, 제목 처리, 글꼴, 강조 처리도 유지합니다.
- 나머지 유형은 테마 팔레트에 연동됩니다. 한지에는 제목 아래 INFO가 없으며, 느와르 도장은 TOP SECRET입니다.

## 설정과 적용 순서

1. 프로필 `use_legacy_status=true`: 모든 테마와 채팅방 선택보다 우선해 레거시를 사용합니다.
2. 채팅방 `use_theme_code_block=false`: 저장한 `code_block_style`을 고정합니다. 상속을 켜도 마지막 고정 선택은 지우지 않습니다.
3. 나머지는 현재 적용된 테마의 `code_block_style`을 사용합니다. 미지정 값과 내장 테마는 기본입니다.

테마 편집기에 상태창 유형을 지정합니다. 채팅방의 **테마 코드블록 사용**은 낮·밤 설정 아래에 있으며, 끄면 고정 유형 선택이 나타납니다. 전역 **레거시 상태창 사용**은 작품 테마 기본 사용 아래에 있습니다.

## 배포 및 검증

`20261108145957_status_codeblock_styles.sql`을 먼저 적용한 뒤 프론트엔드를 배포합니다. 기존 테이블에 표시 설정 열만 추가하며 색상·대화 내용·RLS는 변경하지 않습니다.

`npm run test:code-blocks`는 기존 레거시와의 렌더링 동일성, 실제 Markdown 파이프라인, 우선순위, 마이그레이션 및 RLS를 검증합니다. `scripts/test-single-theme-ui.mjs`는 실제 설정 핸들러의 저장·복사·재진입과 ThemeManager 적용을 검증합니다.
