# 작품 테마의 낮·밤 전환

배포 전에 `supabase/migrations/20261015020249_day_night_work_themes.sql`, `supabase/migrations/20261015022514_stale_day_night_branch_recovery.sql`, `supabase/migrations/20261015043406_time_theme_conditions.sql`을 순서대로 적용해야 합니다.

1. 채팅방에서 **유동적**, 라이트 선호를 선택하고 **다크 버전을 밤 테마로 사용**을 켭니다. 기본값은 OFF입니다.
2. 시간 전환 ON이면 모든 작품 복수 테마를 `이름:낮`, `이름:밤` 두 개의 독립된 AI 목록 항목으로 전달합니다. 개별 테마 체크 여부와 관계없이 적용하며 기존 AI 적용 조건 뒤에 각각 아래 문장을 추가합니다. 단일 테마는 기존 이름과 조건, 색상을 유지합니다.

```text
해가 떠 있는 낮에 사용하세요.
해가 완전히 진 밤애 사용하세요.
```

`{{theme::이름:낮}}`은 라이트 버전, `{{theme::이름:밤}}`은 다크 버전을 표시합니다. 실제 시계와 무관한 이야기 속 시간이며, 새 태그가 없는 경우 기존 keep 동작을 유지합니다. 처음 켰을 때 해당 테마는 낮 버전에서 시작합니다.

밤 상태는 `sessions.theme_period`에 따로 저장합니다. 전역 라이트 선호와 `theme_variant`를 밤 때문에 다크로 바꾸지 않습니다. 다크 선호 또는 고정 테마에서는 시간 전환이 작동하지 않습니다. 옵션을 끄면 현재 낮·밤 상태가 해제되고 목록이 원래 이름으로 복원됩니다.

작품 테마의 **시간 전환을 켰을 때만 사용** 체크는 자동 선택 목록에 포함되는 조건입니다. 기본 OFF이며 단일·복수 테마 모두 설정할 수 있습니다. 체크하거나 해제해도 테마 방식·색상을 바꾸거나 색상 버전을 추가하지 않습니다. 시간 전환이 작동하지 않으면 체크한 테마를 AI 목록과 응답 선택에서 제외합니다. 유동적에서 해당 테마를 이미 사용 중이거나 작품 기본값으로 상속받은 경우에는 전역 테마로 돌아갑니다. 고정 모드에서 명시적으로 선택한 테마는 유지합니다.

시간 전환이 작동하지 않거나 해당 테마가 단일인 경우, 과거 `{{theme::이름:낮}}`·`{{theme::이름:밤}}` 태그는 요청 사본에서 일반 `{{theme::이름}}`으로 정리합니다. 저장된 메시지·요약 원본과 캐시 기준 메시지 ID는 변경하지 않습니다. 고정 모드에서는 일반 이름 및 낮·밤 테마 태그 전체를 전송에서 제외합니다.

마이그레이션은 기존 `themes.day_night_enabled` 컬럼을 위 사용 조건으로 유지하며 단일 테마를 막던 제약을 수정합니다. 세션의 낮·밤 상태는 모든 작품 복수 테마에 허용합니다. 기존 체크값·색상·기록은 변경하지 않으며 기존 RLS 권한을 그대로 사용합니다. 일반 테마 이름과 생성 태그가 충돌하면 임의의 테마를 적용하지 않으며, 새 작품 테마 이름 끝의 `:낮`·`:밤`은 예약되어 있습니다.

작품 복수 테마의 체크를 해제해도 낮·밤 상태를 유지합니다. 단일로 전환한 뒤 오래된 화면에서 채팅을 분기하면 DB가 더 이상 사용할 수 없는 낮·밤 상태만 해제하고 분기와 팔레트는 보존합니다.
