# 작품 테마의 낮·밤 전환

배포 전에 `supabase/migrations/20261015020249_day_night_work_themes.sql`을 적용해야 합니다. 운영 DB 적용은 아직 보류되어 있습니다.

1. 작품 테마를 라이트·다크 방식으로 제작하고 **다크·라이트 시간 전환에 사용**을 켭니다. 기본값은 OFF이며 단일·전역 테마에는 적용하지 않습니다.
2. 채팅방에서 **유동적**, 라이트 선호를 선택하고 **다크 버전을 밤 테마로 사용**을 켭니다. 이 옵션도 기본값은 OFF입니다.
3. AI 목록은 해당 테마를 `이름:낮`, `이름:밤` 두 항목으로 전달합니다. 기존 AI 적용 조건 뒤에 각각 아래 문장을 추가합니다.

```text
해가 떠 있는 낮에 사용하세요.
해가 완전히 진 밤애 사용하세요.
```

`{{theme::이름:낮}}`은 라이트 버전, `{{theme::이름:밤}}`은 다크 버전을 표시합니다. 실제 시계와 무관한 이야기 속 시간이며, 새 태그가 없는 경우 기존 keep 동작을 유지합니다. 처음 켰을 때 해당 테마는 낮 버전에서 시작합니다.

밤 상태는 `sessions.theme_period`에 따로 저장합니다. 전역 라이트 선호와 `theme_variant`를 밤 때문에 다크로 바꾸지 않습니다. 다크 선호 또는 고정 테마에서는 시간 전환이 작동하지 않습니다. 옵션을 끄면 현재 낮·밤 상태가 해제되고 목록이 원래 이름으로 복원됩니다.

기능이 작동하지 않거나 해당 작품 테마의 체크가 꺼진 경우, 과거 `{{theme::이름:낮}}`·`{{theme::이름:밤}}` 태그는 요청 사본에서 일반 `{{theme::이름}}`으로 정리합니다. 저장된 메시지·요약 원본과 캐시 기준 메시지 ID는 변경하지 않습니다. 고정 모드에서는 기존처럼 테마 태그 전체를 전송에서 제외합니다.

마이그레이션은 기본 OFF인 세 컬럼과 무결성 제약·트리거를 추가하며 기존 색상과 기록을 변경하지 않습니다. 기존 RLS 권한을 그대로 사용합니다. 일반 테마 이름과 생성 태그가 충돌하면 임의의 테마를 적용하지 않으며, 새 작품 테마 이름 끝의 `:낮`·`:밤`은 예약되어 있습니다.
